# pyqt-study

## 📝 프로젝트 소개
PyQt5 프레임워크의 기본적인 구성 요소인 위젯(Widgets), 레이아웃(Layouts), 드래그 앤 드롭 동작 및 시그널-슬롯(Signal & Slot) 기반 이벤트 모델을 상세 공부한 코드 모음입니다.

## 🛠 주요 사용 기술
- Python 3
- PyQt5 (GUI FrameWork)

## 📂 주요 파일 구성
- `06_1.시그널.이벤트.py`: 사용자의 마우스 클릭, 윈도우 창 닫기 등의 동작에 반응하는 이벤트 리스너 핸들링
- `07_1.대화상자(QInputDialog).py` ~ `07_3.대화상자`: 시스템 표준 팝업 대화상자(텍스트 입력, 색상 선택, 폰트 선택) 개발 예제
- `08_3.여러위젯(QProgressBar).py`: 진행 상태를 바 형태로 실시간 표현해 주는 ProgressBar 위젯 제어
- `10_1.드래그&드롭(dragEnterEvent).py`: 외부 파일을 마우스로 끌어다 창에 올리는 Drag and Drop 입력 처리 예제
